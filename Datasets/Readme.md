## 📂 Datasets

This folder contains the datasets used for training, testing, and evaluating the machine learning models throughpout my learning.

### 📋 Description

The datasets include multiple features (columns) relevant to the problem being solved. These features I used to train and validate the models after appropriate preprocessing steps such as cleaning, encoding, and feature scaling.

Depending on the task, selected columns from the datasets were used to:
- Build the feature matrix (`X`)
- Define the target/output variable (`y`)
- Apply feature scaling where required
- Perform train-test splitting for model training and evaluation
