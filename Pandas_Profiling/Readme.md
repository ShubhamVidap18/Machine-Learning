📊 Pandas_Profiling
This folder contains a detailed data analysis report generated using the pandas-profiling (now ydata-profiling) library in Python.

📄 About
pandas-profiling is an open-source Python library that automatically generates comprehensive data profiling reports for a given pandas DataFrame. It helps in understanding the structure, quality, and characteristics of your dataset in just a few lines of code.

The profiling report includes:

Dataset overview (number of variables, observations, missing values, etc.)

Detailed statistics for each column

Correlation matrix

Missing value matrix

Duplicates

Interactions and warnings

Visualizations and summaries
