# 📊 Pandas_Profiling

This folder contains a detailed data analysis report generated using the `pandas-profiling` (now known as `ydata-profiling`) library in Python.

## 📄 About

`pandas-profiling` is an open-source Python library that automatically generates comprehensive profiling reports for a pandas DataFrame. It is a powerful tool to quickly understand the structure, distribution, correlations, and quality of your dataset with just a few lines of code.

The profiling report includes:
- Dataset overview (variables, observations, missing cells, etc.)
- Type inference and statistics for each feature
- Correlation analysis
- Missing value visualizations
- Duplicate detection
- Interaction and alerts
